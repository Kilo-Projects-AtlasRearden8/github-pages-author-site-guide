# Publishing a Free Author Site with GitHub Pages

A beginner's manual for writers, nurses, teachers, and anyone else who wants a home on the internet — no coding experience required.

Welcome. This manual walks you through publishing a free author website with GitHub Pages, step by step: create a repository, add GitHub Pages, choose a theme, edit your content, and publish. It was written for Dylan Asdale — registered nurse turned AI author and founder of Asdale Dynamics, LLC — and for anyone building their first author site.

Every step is written in plain English. No jargon without an explanation. You do not need to be a developer.

## What you will build

A free website at `yourusername.github.io` that introduces you as an author, lists your books, and tells readers how to contact you. This manual includes a ready-to-use static HTML site template in `site/` that you can copy into your repository and publish today.

## Before you begin

- A computer with a web browser
- A free GitHub account
- About 30 minutes
