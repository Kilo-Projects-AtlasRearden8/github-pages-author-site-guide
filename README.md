# Free Author Site with GitHub Pages — Beginner Manual

A plain-English, step-by-step guide to publishing a free author website with GitHub Pages, plus a ready-to-use static HTML author site template.

## Who this is for

This manual was written for Dylan Asdale — a registered nurse turned AI author and founder of **Asdale Dynamics, LLC** (Indiana, formed October 2026) — and for anyone publishing their first author site. No coding experience is required. Every step is explained in plain language, step by step, never condescending.

## What is inside

- `docs/` — the beginner manual: create a repository, add GitHub Pages, choose a theme, edit your content, publish, and a launch checklist.
- `site/` — a complete static HTML author site template you can copy into your repository and publish today.
- `LICENSE` — MIT License. Copyright (c) 2026 Asdale Dynamics, LLC.

## Credit

Created for and credited to **Asdale Dynamics, LLC**, an Indiana LLC focused on beginner-friendly AI education, books and guides, practical tools, and small-business resources for authors.

## How to use

Read `docs/` in order. Each step references screenshots (included as labeled placeholder images in `docs/screenshots/`). When you reach step 4, copy the files in `site/` into your repository, edit them with your own details, and publish.
